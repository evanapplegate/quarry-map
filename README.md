# Quarry map

MapLibre map of English building-stone quarries (BGS Building Stone Database for England) over BGS 1:625k bedrock geology, with 3D terrain on a globe.

- `index.html`: the map
- `basemap_style.json`: Esri Dark Gray Canvas vector style plus terrain and hillshade
- `data/quarries.geojson`, `data/bedrock_tiles/`, `data/bedrock_key.json`: built data
- `scripts/`: rebuilds the data from the source files (not in this repo)

Labels render in Optima from the viewer's installed fonts, with a sans-serif fallback elsewhere.

Data: British Geological Survey © UKRI. Basemap: Esri. Terrain: Mapzen terrain tiles on AWS.

## Lightbox viewer (Three.js)

`viewer/` is a standalone Vite app that hangs the map (`viewer/public/map_sketch_v1.png`, a copy of `crim.png`) as two amber lightboxes in walnut frames on a paneled wall, lit only by the maps: an A1 on the left and an A2 on the right, each on its own raised panel. The glass (visible map) is exactly A1 or A2; the frame extends beyond it.

Live: https://evanapplegate.github.io/quarry-map/lightbox/

```
cd viewer
npm install
npm run dev          # http://localhost:5174
npm run build:pages  # rebuilds ../lightbox/, which GitHub Pages serves from main
```

Or start the `lightbox-viewer` entry in `.claude/launch.json`. The app serves its own copies of the map (as `map_sketch_v1.png`) and `radian_maps_logo.svg` from `viewer/public/`; re-copy them after editing the originals, then rebuild and commit `lightbox/` to publish. Walnut (frames) and MDF (backers) textures are generated by `python3 scripts/make_walnut.py` into `viewer/public/tex/`.

- Map loads at full native size (7016 x 9933) with mipmaps, 16x anisotropy and sRGB decoding; if it exceeds the GPU max texture size it is split into tiles. `?tile=4096` forces tiling for testing.
- Panel (Optima, EB Garamond fallback from Google Fonts): frame style (plain walnut or reed-and-ribbon molding after `molding.png`), light color, and a Download full map link to `map_sketch_v1.png`. Intensity and bloom are fixed in `state` at the top of `viewer/src/main.js`. `?style=molding` opens on the molding. Texture details (size, tiling, anisotropy) go to the browser console.
- Each lightbox has a 5 mm cord leaving the bottom centre of the frame, hanging plumb to the floor and running to a twin socket on the skirting under the centre stile (`viewer/src/cord.js`).
- Orbit with drag, zoom with scroll, pan with right-drag (held to the artwork, down as far as the socket). Zoom-out stops at 1.6x the distance that frames both lightboxes for the current window shape (`ZOOM_OUT` in `viewer/src/main.js`), and the camera stays between floor and ceiling. Orbit behind the wall to see the flat brown MDF backers and the engraved logos (bottom-left).
